乒乓球约战

云数据库结构

按当前云函数的写入和读取整理。线从引用字段连到被引用字段。按住一张表可以拖动。

openid 引用 写入时抄一份 没有连线的集合，代码里没有外键

events

约战

创建、编辑、删除比赛

  • _id文档 id
  • creatorOpenid发起人
  • creatorName抄昵称
  • name最多 30 字
  • startTimeYYYY-MM-DD HH:mm
  • location最多 40 字
  • description最多 300 字
  • format积分赛 / 循环赛 / 淘汰赛
  • statusupcoming / ongoing / finished
  • maxPlayers0 为不限
  • signupCount创建时为 0
  • createTime服务器时间
  • updateTime服务器时间

users

球友

登录时创建。资料页改昵称和头像

  • _id文档 id
  • openid业务主键
  • nickname会被抄走
  • avatar会被抄走，可空
  • userNo注册序号
  • profileReady是否保存过资料
  • score积分，初始 1000
  • totalMatches场次
  • winMatches胜
  • loseMatches负
  • createTime服务器时间
  • updateTime服务器时间

matches

对阵

记一场一对一比分

  • _id文档 id
  • player1Openid记录人
  • player2Openid对手
  • player1快照

    openid、nickname、avatar、score

  • player2快照

    字段与 player1 相同

  • scoreChange积分增减

    player1、player2

  • winnerplayer1 / player2 / draw
  • matchType现为 friendly
  • location可空
  • status写入为 completed
  • createTime服务器时间

clubs

球馆

只有查询。和 users、events、matches 都没有外键。

  • _id文档 id
  • name名称
  • city城市
  • location地点
  • description介绍
  • memberCount按人数排序
  • totalScore按总积分排序
  • matchCount比赛场次

注册序号来自 counters 里的一条文档 userSeq，字段 n 在事务里加一。

报名名单不在任何集合里，存在手机本地的 eventSignups。signupCount 创建后没有云函数再改。

users.score 是积分。matches.player1.score 是本场比分。

页面上的信用分 creditScore 不在 users 里，读不到时按 80 显示。
